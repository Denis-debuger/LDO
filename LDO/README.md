# LDO — Let's Do It

Персональная фитнес-платформа на **HTML**, **CSS**, **JavaScript** и **PHP**.

## Назначение сайта

LDO — это фитнес-сервис, который объединяет в одном месте:
- учёт тренировок и питания;
- контроль веса и личного прогресса;
- расчёт КБЖУ и поддержку целей (похудение, набор массы, поддержание формы);
- образовательный контент и администрирование данных.

Пользователь получает личный кабинет, дневник активности и инструменты для принятия решений на основе данных.

## Что можно добавить дальше

- **Планы и цели на период**: недельные/месячные цели с чек-листами выполнения.
- **Push/email-напоминания**: уведомления о тренировках, воде, приёмах пищи.
- **Интеграции с носимыми устройствами**: синхронизация шагов, пульса и сна.
- **Геймификация**: уровни, бейджи и серии посещений для мотивации.
- **AI-рекомендации**: персональные советы по нагрузке и питанию.
- **Социальные функции**: друзья, челленджи, комментарии к прогрессу.
- **Мобильная версия/PWA**: быстрый доступ с телефона и офлайн-режим.

## Стек

- **PHP** — серверная логика, авторизация, БД, роутинг
- **HTML** — разметка страниц (в PHP-шаблонах)
- **CSS** — стили (чёрно-жёлтая тема)
- **JavaScript** — валидация форм, графики, интерактивность

## Установка (XAMPP)

1. Клонируйте или скопируйте проект в любую папку внутри `C:\xampp\htdocs\` (например: `C:\xampp\htdocs\IS-4_YP_2026\LDO\LDO\`).

2. Создайте БД и примените схему:
   ```bash
   mysql -u root < db/schema.sql
   ```
   Или откройте phpMyAdmin, создайте БД `ldo`, скопируйте и выполните содержимое `db/schema.sql`.

3. Настройте `app/config.php` при необходимости:
   - `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` — параметры MySQL
   - `DEV_SHOW_RESET_LINK` — показывать ссылку сброса пароля на экране (для разработки)

4. Создайте первого администратора:
   - **Через браузер**: откройте `http://localhost/LDO web-site/create_admin.php`
   - **Через командную строку**: `php create_admin.php`
   
   По умолчанию создаётся: `admin@ldo.local` / `admin123`

## Безопасность

- Пароли хэшируются через `bcrypt` (`password_hash` / `password_verify`)
- Защита от CSRF — токен в формах
- Подготовленные запросы (PDO) — защита от SQL-инъекций
- `htmlspecialchars` при выводе — защита от XSS
- Валидация email и минимальная длина пароля (8 символов)

## Переход на Symfony + React

- ReactJS подключён глобально в layout и используется на всех страницах сайта (общий React shell + React-виджеты страницы профиля).
- Добавлен bridge в `index.php`: при `USE_SYMFONY=1` и наличии `symfony/vendor/autoload.php` запрос делегируется в Symfony Kernel (`App\Kernel`).
- Пока bridge выключен по умолчанию, текущий PHP-роутинг продолжает работать как fallback.

## Дополнительно

- **Аватар** — загрузка в профиле (JPG, PNG, GIF, WebP, до 2 МБ). Хранятся в `uploads/avatars/`
- **Миграции** — для существующей БД:
  - `mysql -u root ldo < db/migrations/001_avatar_and_diary.sql` (аватар и дневник)
  - `mysql -u root ldo < db/migrations/002_articles_media.sql` (медиа в статьях)
  - `mysql -u root ldo < db/migrations/003_diary_food.sql` (детальный дневник и питание)
  - `mysql -u root ldo < db/migrations/004_admin_security_moderation.sql` (модерация, аудит админов, панель безопасности, категории, бэкап/импорт/экспорт)
- **Медиа на главной** — отредактируйте `config/home_media.php`, добавьте пути к изображениям/видео/GIF. Папки: `assets/images/home/` и `uploads/home/`
  - Для GIF на задний фон: установите `'type' => 'gif'` в первом элементе массива `$HOME_MEDIA`

## Разделение на Backend (PHP) и Frontend (React SPA)

Проект разделён на две части:

- `backend/` — PHP backend с API (`backend/public/api.php`)
- `frontend/` — React SPA (Vite)

### Backend API

Запуск локально:

```bash
php -S 0.0.0.0:8080 -t backend/public
```

Доступные endpoint'ы:

- `GET /api.php?endpoint=health`
- `GET /api.php?endpoint=profile` (требует авторизацию в PHP-сессии)
- `POST /api.php?endpoint=profile`

### Frontend (React)

```bash
cd frontend
npm install
npm run dev
```

SPA использует backend API для загрузки/сохранения профиля и показывает калькулятор ИМТ.

## Частые проблемы при запуске

- **Вместо сайта открывается JSON** (`{"ok":true,"service":"ldo-backend"...}`):
  - это значит, что запущен backend API (`-t backend/public`), а не основной сайт;
  - для сайта запускайте сервер из корня проекта: `php -S 127.0.0.1:8080 -t .` и открывайте `http://127.0.0.1:8080/index.php?r=home`.

- **PowerShell пишет `php не распознано`**:
  - запускайте через полный путь: `C:\xampp\php\php.exe -S 127.0.0.1:8080 -t .`;
  - либо добавьте `C:\xampp\php` в переменную среды `PATH`.

- **Во frontend виден старый шаблон Vite (`count is 0`)**:
  - убедитесь, что запущена папка именно этого проекта: `...\LDO\LDO\frontend`;
  - перезапустите dev-сервер после изменений: `npm install` и `npm run dev`.
