# LDO Frontend (React SPA)

Фронтенд полностью переведён на React и теперь представляет собой единую SPA-оболочку с разделами проекта.

## Что уже перенесено

- Главная
- Профиль
- Калькулятор КБЖУ
- Программы тренировок
- Справочник упражнений
- Дневник
- Прогресс
- Статьи
- Авторизация
- Админ-раздел

## Запуск

```bash
npm install
npm run dev
```

Приложение использует общую дизайн-систему в чёрно-жёлтой теме и может быть интегрировано с API из `backend/public/api.php`.
