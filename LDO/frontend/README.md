# LDO Frontend (React SPA)

Фронтенд переведён на React и покрывает страницы из `app/views` в виде SPA с hash-роутингом.

## Перенесённые разделы и функционал

- Главная (дашборд)
- Профиль (редактирование данных)
- Калькулятор КБЖУ (авторасчёт по профилю)
- Программы (список + добавление)
- Упражнения (список + добавление)
- Дневник тренировок:
  - список записей
  - добавление
  - просмотр
  - редактирование
  - удаление
- Прогресс (график веса + история)
- Статьи (поиск, просмотр, добавление, комментарии)
- Авторизация (вход/регистрация/сброс)
- Админ-панель (модерация, пользователи, логи)

## Хранение данных

На текущем этапе данные сохраняются в `localStorage` (`ldo-react-store`) для автономной работы UI.

## Запуск

```bash
npm install
npm run dev
```
