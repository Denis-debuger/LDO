# LDO Frontend (React SPA)

Frontend проекта полностью переведён на React и работает как единое SPA-приложение.

## Что реализовано

- Единая React-навигация по основным разделам проекта (главная, профиль, КБЖУ, дневник, программы и др.).
- Полноценные React-экраны для:
  - **Профиля** (редактирование параметров пользователя);
  - **Питания** (добавление/удаление продуктов, список того, что съедено);
  - **КБЖУ** (сводка по фактическому потреблению за день).
- Остальные разделы переведены на React-оболочку и готовы к подключению API бизнес-логики.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию frontend ожидает API по адресу:

```text
http://127.0.0.1:8080/api.php
```

Можно изменить через переменную окружения:

```bash
VITE_API_BASE=http://127.0.0.1:8080/api.php npm run dev
```

## Сборка
