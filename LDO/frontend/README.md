# LDO Frontend (React)

Сделаны две статические страницы проекта с полноценным контентом:

- `#/home` — Главная (hero, недельный план, фокус по питанию, карточки модулей, новости, блок «Как начать»)
- `#/profile` — Профиль (данные пользователя, цели на месяц, личные рекорды)

## Запуск

```bash
npm install
npm run dev
```

Навигация между страницами реализована в верхнем меню.
